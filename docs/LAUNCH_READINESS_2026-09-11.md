## 本轮调整

1. **模型上下文的边界可见。** ReportAgent 复用一次初始 RAG 装配，增加召回、
   纳入、截断、丢弃和字符预算说明。截断意味着未看到的限制、否定或例外仍未知，
   不能声称获得完整原文支持。Evidence Trail 展示的是“当前规则的初始上下文预览”，
   不是历史报告、结构修复或文字修订实际收到的上下文证明。
2. **缺失值口径一致。** 模型输入与界面共用显示函数；空值、非有限数和无效百分比
   显示为 `To be confirmed`，真实 `0%` 保留。未修改原始数据、人口聚合口径或审批规则。
3. **私有下载可诊断。** Blob 下载显示可访问的成功请求/失败提示，不再无反馈；
   只称 `Download requested`，不谎称磁盘保存完成。动态 iframe 高度保留提示可见性。
   仍是授权会话内交付、8 MiB 上限，无新增公开下载地址或服务端回调。
4. **保存语义明确。** 云端成功提示明确只保存 Markdown；浏览器会话和审签工作区
   不随之恢复，审计另行保留。用户应在关闭会话前下载所需文件。
5. **容器重启测试读旧证据。** smoke 首阶段通过真实 API 写入两条合成审计事件
   和一条不含正文的 Trace；重启阶段先验证原文件 SHA、审计链/head、Trace 结构、
   原 UTC 日配额，再执行后续测试。Linux boot ID 与 PID 1 启动时间必须变化，
   不能只重跑脚本冒充重启。索引身份和 mtime 检查保留。

smoke 只允许显式测试模式、已验证的自制测试语料和新的隔离卷；拒绝 Railway
生产环境标识、路径覆盖和敏感审计正文存储。旧 sentinel 不能充当新版验收证据。
不要在真实 `/data` 上运行该写入测试；线上验证采用以下只读路径。

## 导出验证的边界

使用取回的原始 Markdown 字节在本地重新运行现有 PDF/DOCX 导出器，没有编辑正文。
这属于**本地导出重现**，不是当时从登录网页下载到的原始云端 PDF/DOCX/ZIP。

- PDF：15 页全部渲染并逐页检查；中文合成审核者、表格跨页和长来源字段可见，
  未发现内容裁切或近空白页。所用本地字体不代表 Linux 容器字体的视觉证明；
  容器中文文本可提取性另由 Docker smoke 检查。
- DOCX：ZIP/XML 结构、15 个表格及预期中文/审核/缺失值文字检查通过；
  文档检查运行时缺少绑定的 LibreOffice，规范渲染器失败，
  **Word 逐页版面验收仍未完成**。不借用用户桌面 Word/LibreOffice 绕过依赖约束。
- 浏览器：受保护下载的六种格式与字节一致性、匿名隔离和失败反馈有 Chromium
  自动化验证；内置浏览器静默阻止下载时只提示用户检查，不宣称已落盘。
  Firefox/WebKit 和修复后线上完整下载包尚无本轮验收证据。

正式新样例发布仍需真实生成绑定、实际下载包及跨格式检查，不用本地重现填补这些项。

## RAG：保留已知不足，不为过关改变指标

既有 CPU 诊断的 12 个词面目标仍为未裁剪检索块中命中 10/12、实际初始可见片段中命中 9/12。
Tasmania 的目标限制语句在原始块的零基偏移 2,255、清理后块的零基偏移 2,280 处开始，
超过清理后文本的 2,200 字符前缀预算；NT 仍有两个
`no_match`。这些是诊断限制，不是通过的语义质量成绩。

本轮没有调整查询、锚点、阈值、题库、2,200/8,000 字符预算或 v1 装配 manifest，
没有重建本地或线上索引。新增提示改变完整初始 Prompt，但不改变其中的 RAG 块。
旧诊断只证明其绑定的旧源提交，后续实际 Prompt 重测须生成新文件，不回写旧结果。
继续片段、关注点检索或重新分块，应独立设计正反例后评估，再考虑切换索引。
