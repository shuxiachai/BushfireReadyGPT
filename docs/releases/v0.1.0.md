# BushfireReadyGPT v0.1.0

BushfireReadyGPT `v0.1.0` is the first public government-pilot MVP release of the Australia-focused bushfire preparedness reporting assistant.

## Highlights

- Local-first language-model inference through Ollama, with no OpenAI API key required.
- Form-driven Streamlit workflow for council, school and community preparedness scenarios.
- Deterministic multi-agent pipeline covering profile, Australian sources, community vulnerability, risk context, planning, report context and structural quality checks.
- Australia-wide State, SA4, SA3 and SA2 geography selection using local ABS / ASGS-derived context.
- O1, P2, R3, A4 and U0 provenance labels that distinguish official references, processed data, configured rules, AI-generated narrative and unverified user inputs.
- Governed report revisions with report IDs, version lineage, approval reset and per-version audit JSON.
- Human review checklist and sign-off controls before organisational approval can be recorded.
- Markdown, PDF, DOCX and pilot ZIP package exports.
- Windows double-click, VSCode task and PowerShell startup paths with Ollama and duplicate-instance checks.

## Validation

- 28 fast unit, integration, export, Streamlit smoke and AppTest workflow tests.
- One real Chromium end-to-end workflow test.
- GitHub Actions validation on Python 3.11 and Python 3.13.

## Safety And Product Boundary

This release is a preparedness planning prototype. It does not provide live fire conditions, fire bans, evacuation orders, confirmed safe routes, confirmed safe assembly points or life-safety decisions. Generated reports remain drafts until reviewed by the responsible organisation. Follow official emergency services and call `000` when life is at risk.

The release is suitable for portfolio demonstration and controlled pilot discussion. Authentication, immutable organisational approval, production hosting, legal review, privacy controls and formal data-licence decisions remain future work before commercial or government deployment.
