# BushfireReadyGPT v0.2.0

BushfireReadyGPT `v0.2.0` is the portfolio-focused local RAG and reliability
release. It keeps the product inside its preparedness-planning boundary while
making installation, evidence retrieval, report quality and validation easier to
demonstrate in an interview.

## Highlights

- Added a conventional local RAG pipeline using Ollama `embeddinggemma`, Qdrant,
  BM25 and reciprocal-rank fusion.
- Expanded the catalog to nine official preparedness pages covering all eight
  Australian states and territories.
- Added page-level licence URLs, reuse classifications, verification dates and
  retrieval-time source provenance.
- Added deterministic abstention for live/life-safety requests and answerability
  thresholds for unsupported free-text questions.
- Expanded the retrieval benchmark to 68 answerable queries and 16 hard
  negatives, plus a three-scenario real-model report benchmark.
- Added one-click Windows setup, startup preflight checks, a dedicated
  `bushfire-ready-qwen` model with a 16K context window and Windows CI.
- Added an automatic structural repair pass for incomplete model reports while
  retaining deterministic evidence tables and safety notices outside model text.
- Enforced HTTPS for external model endpoints, bounded in-memory model history
  and improved interrupted-response handling.
- Made official-source reachability checks concurrent with a shared per-source
  timeout budget.
- Added a repository-wide formatter check and a maximum cyclomatic complexity of
  20, with the three largest functions split into focused helpers.

## Retrieval baseline

On the documented 2026-08-21 local `embeddinggemma` baseline:

- Passage Recall@5: `0.9706`
- Mean reciprocal rank: `0.8922`
- Top-1 accuracy: `0.8235`
- Unanswerable accuracy: `1.0000`
- Average latency: approximately `104 ms`
- P95 latency: approximately `126 ms`

These figures are project-benchmark results, not production accuracy claims.

The final three-scenario real-Ollama benchmark passed all structural, evidence
binding and source-attribution checks, produced no unsafe live-condition claims
and averaged `29.38 seconds` per full governed report on the release machine.
This small deterministic scenario set is a regression signal, not a general model
quality estimate.

## Upgrade

On Windows, close the app and run:

```text
Start BushfireReadyGPT.bat
```

The single launcher preserves custom environment settings but migrates the exact
legacy `OLLAMA_MODEL=qwen2.5:7b` default to `bushfire-ready-qwen`. On every run it
checks dependencies, models and RAG, then downloads or rebuilds only components
that are missing or outdated before starting the app.

## Safety and legal boundary

The release does not ingest or interpret live incidents, warnings, fire bans,
evacuation orders, safe routes or confirmed assembly points. Restricted or
ambiguous source-page reuse classifications still require legal or rights-holder
review before redistribution or commercial deployment. Reports remain drafts
requiring accountable human review.
