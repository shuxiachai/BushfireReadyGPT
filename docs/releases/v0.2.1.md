# BushfireReadyGPT v0.2.1

BushfireReadyGPT `v0.2.1` is a performance, startup reliability and architecture
maintenance release. It keeps the local RAG and human-review workflow from
`v0.2.0`, while making the application faster and easier to demonstrate on a
Windows interview machine.

## Highlights

- Replaced the legacy assistant/thread abstraction with a small stateless
  `GovernedModelClient`; every request sends only the current governed prompt and
  no provider-side conversation history or tools.
- Tuned the local `bushfire-ready-qwen` model from a 16K to an 8K context window,
  capped report output at 2,300 tokens and bounded narrative length to 900-1,200
  words.
- Reduced RAG prompt payloads and excluded deterministic evidence tables and
  sign-off content from model revision prompts.
- Retained one self-checking Windows launcher: existing Python dependencies,
  Ollama models and RAG assets are reused, while only missing or outdated
  components are installed or rebuilt.
- Added a minimal Streamlit configuration that disables telemetry and hides the
  development toolbar in normal use.
- Simplified the planning form, made pilot-example loading explicit, moved
  reviewer identity to the Review & Export step and showed the evidence trail by
  default.
- Added a Qdrant compatibility shim that prevents the Python 3.13 SQLite resource
  warning without changing retrieval behaviour.
- Raised the CI coverage gate from 80% to 85% and expanded state, runtime and RAG
  regression coverage.

## Validation baseline

Validated locally on 2026-08-22:

- Unit and integration tests: `191 passed`
- Chromium end-to-end workflow: `1 passed`
- Source coverage: `85.26%`
- Ruff, formatter, Bandit, dependency consistency and lock checks: passed
- PyPI vulnerability audit: no known vulnerabilities found
- Windows launcher preflight: passed; existing dependencies were detected and
  installation was skipped

The 84-question hybrid RAG benchmark passed with:

- Passage Recall@5: `0.9706`
- Mean reciprocal rank: `0.8922`
- Top-1 accuracy: `0.8235`
- Unanswerable accuracy: `1.0000`
- Average retrieval latency: `104.70 ms`
- P95 retrieval latency: `126.57 ms`

The three-scenario real-Ollama benchmark passed every structural, evidence
binding, source-attribution and safety gate in one generation attempt per
scenario. Average full-report latency was `26.24 seconds` on the release machine.
These project benchmarks are regression signals, not production accuracy or
hardware-independent performance claims.

## Upgrade

Close any running copy of the app, then double-click:

```text
Start BushfireReadyGPT.bat
```

The launcher checks the existing environment on every run. It does not reinstall
healthy dependencies or redownload matching models and RAG assets.

## Safety and deployment boundary

The application remains a preparedness-planning assistant. It does not provide
live incidents, warnings, fire bans, evacuation orders, safe routes or emergency
decisions. All generated reports remain drafts that require accountable human
review. The nationwide ABS map bundle is optional, downloaded locally and not
redistributed in this repository.
