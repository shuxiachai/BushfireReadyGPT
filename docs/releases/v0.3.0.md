# BushfireReadyGPT v0.3.0

BushfireReadyGPT `v0.3.0` is a portfolio-evidence and pilot-readiness release. It
makes data limitations visible in every governed report, broadens real-model
regression coverage and ships a current, inspectable demonstration package.

## Highlights

- Added source period, latest year, source age, freshness and geographic-match
  quality to the multi-agent evidence context, Evidence Trail and report tables.
- Added explicit warnings for aging baselines, approximate or unmatched
  geography, synthetic fallback data, transport limitations and the non-live
  product boundary.
- Expanded real-Ollama evaluation from three scenarios to all six supported
  planning scenarios plus live-request refusal and no-RAG degradation cases.
- Hardened structural repair and RAG title/agency attribution while keeping
  generated text bound to deterministic evidence.
- Added a current Cairns Council sample in Markdown, PDF and DOCX plus its
  hash-verified `pilot-export-v3` package.
- Improved wide export tables and placed the DOCX human sign-off section on a
  dedicated page; every sample PDF/DOCX page was rendered and visually reviewed.
- Added five current product screenshots and an 89-second local demonstration
  video for portfolio review.
- Added a repeatable, privacy-minimised 3-5 person pilot protocol, feedback form
  and results register. External participant sessions remain pending and are not
  represented as completed validation.
- Consolidated Windows setup and startup into `Start BushfireReadyGPT.bat` and
  `start_app.ps1`. Every run reuses healthy dependencies, Ollama models and RAG
  assets and repairs only missing or stale components; the redundant
  `setup.ps1` file was removed.

## Validation baseline

Validated locally on 2026-08-22:

- Automated tests, including Chromium end to end: `209 passed`
- Source coverage: `85.36%`
- Ruff, Bandit, dependency consistency, lock and public vulnerability checks: passed
- Windows launcher preflight: passed
- Committed sample schema/hash/content verification: passed
- PDF sample: `14` pages, rendered and visually reviewed
- DOCX sample: `15` pages, rendered and visually reviewed

The 84-question hybrid RAG baseline remains:

- Passage Recall@5: `0.9706`
- Mean reciprocal rank: `0.8922`
- Top-1 accuracy: `0.8235`
- Unanswerable accuracy: `1.0000`

The eight-case real-Ollama report benchmark passed its structural,
evidence-binding, RAG-attribution, behavior, topic, contamination, unsafe-claim
and report-size gates. One case required structural repair (`12.5%`); average
full-report latency was `27.97 seconds` on the release machine. These results are
engineering regression signals, not production, factual or stakeholder
validation claims.

## Upgrade

Close any running app terminal and double-click:

```text
Start BushfireReadyGPT.bat
```

No separate setup script is required. The first run can take longer if Python
packages or Ollama models are missing; later runs skip components that already
match the project configuration.

## Safety and deployment boundary

The application remains a local single-user preparedness-planning assistant. It
does not provide live incidents, warnings, fire bans, evacuation orders, safe
routes or emergency decisions. Reports remain drafts until accountable human
review. Authentication, independently verified identity, legal/licence review,
external immutable records and secure multi-user deployment remain future work.
