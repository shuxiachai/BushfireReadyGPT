# v0.3.0 Example Export Package

These files were generated from the built-in **Cairns Council pilot** using the local Ollama report model and the verified local RAG index on 22 August 2026.

- `cairns-council-report.md` — governed Markdown report.
- `cairns-council-report.pdf` — presentation-ready PDF export.
- `cairns-council-report.docx` — editable Word export.
- `cairns-council-pilot-package.zip` — report, exports, audit record, data register, sign-off record and package manifest.

The content is a demonstration draft, not live emergency advice. Dates in the package identify when the demonstration was generated; official sources must be rechecked before any real use.
